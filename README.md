# FastAPI Project

Este proyecto es una API REST construida con **FastAPI**. Sigue los pasos a continuación para configurar tu entorno local y levantar el servidor de desarrollo de manera correcta, evitando conflictos con las dependencias del sistema.

---

## 🛠️ Requisitos Previos

Antes de comenzar, asegúrate de tener instalado en tu sistema:
* Python 3.10 o superior
* `pip` (Administrador de paquetes de Python)
* `virtualenv` (opcional, pero recomendado)
